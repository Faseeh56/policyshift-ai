# PolicyShift AI

Evidence-backed e-commerce policy change analysis powered by Google's Gemma 4.

## Project Status

Under active development for MLH Hacktoberfest Hack Day 2026.

## Objective

Detect meaningful changes between policy versions and explain their impact on customers and support teams.

## Planned Features

- Gemma 4-powered policy comparison
- Structured change reports
- Source evidence verification
- Interactive user interface
- Automated validation tests

## Technology

Python, Google GenAI SDK, Gemma 4
